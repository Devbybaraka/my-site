02 — About

I like the part where
it finally feels simple.

I started out writing interfaces for a small studio and never stopped caring about the last five percent — the easing curve, the empty state, the label that tells you what happened.

Today I work end to end: research and flows with the product team, the design system in code, the API when it needs to exist, and the launch. I am equally happy joining an existing engineering team for a quarter or owning a whole build from zero.

I care about performance and accessibility because they are the same thing as respect for the person on the other side of the screen. I write TypeScript by default, reach for the simplest tool that works, and document as I go.
